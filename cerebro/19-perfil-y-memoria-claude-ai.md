# Perfil y memoria de claude.ai (listo para pegar)

Todo sale de `01`, `02`, `11`, `14`, `16` y `17`; no hay claves, códigos de acceso, correos ni teléfonos. Si una orden nueva cambia algo, se corrige acá y se vuelve a pegar.

## 4. Cómo cargarlo

1. **Preferencias personales.** Abrí claude.ai → tu nombre abajo a la izquierda → Configuración → General. Pegá el bloque 1 en «¿Qué preferencias personales debería tener en cuenta Claude?» y guardá. Si el cuadro tiene tope, el bloque ya entra.
2. **Memoria.** En Configuración → Capacidades, activá «Generar memoria a partir del historial de chats» si no está activa. Después abrí «Ver y editar la memoria» y agregá los recuerdos del bloque 2. Si tu cuenta no permite editar a mano, abrí un chat nuevo, pegá el bloque 2 y escribí «guardá cada uno de estos recuerdos». Revisá la lista al final y borrá lo que quede repetido o mal.
3. **Instrucciones del proyecto.** Entrá a Proyectos → «CRM COMPLETO» → Instrucciones del proyecto (lápiz o «Establecer instrucciones»). Pegá el bloque 3 y guardá. Vale para los chats comunes y de Cowork del proyecto. Los chats de Code leen el `CLAUDE.md` y el cerebro del repo solos.
4. **Comprobar.** Abrí un chat nuevo dentro del proyecto y preguntá «¿dónde está el cerebro y qué hacés si escribo accesos?». Tiene que contestar la carpeta cerebro/ y la sesión de accesos, en voseo y en masculino.
5. **Mantenerlo al día.** Cuando cambie una orden en `02-ordenes-vigentes.md`, avisale a Claude «actualizá el perfil»: corrige este archivo y vuelven a pegar solo lo que cambió.
