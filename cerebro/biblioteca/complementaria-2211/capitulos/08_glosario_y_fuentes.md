# Glosario y fuentes de consulta

## Términos de Jurídico

| Término | Qué debe entender el cerebro |
| --- | --- |
| ART | Entidad del sistema de riesgos del trabajo; no confundirla con la clínica que atiende |
| Contingencia | Hecho o enfermedad cuya relación con el trabajo y cobertura se analiza |
| Accidente en el trayecto | Tema que requiere revisar recorrido y circunstancias; no confirmar cobertura por la etiqueta |
| Alta médica | Comunicación o decisión sobre la atención; identificar documento y fecha |
| Rechazo | Decisión distinta del alta; revisar qué entidad la emitió y qué se rechazó |
| Secuela | Consecuencia que requiere evaluación; no inferir porcentaje por el nombre de la lesión |
| Dictamen | Documento con una conclusión de un órgano; revisar contenido y notificación |
| Homologación | Actuación formal cuyo alcance se verifica en el expediente; no equivale a una promesa por chat |
| Siniestro | Hecho relacionado con un contrato de seguro; distinguir denuncia y reclamo |
| Franquicia | Condición del contrato de seguro que debe revisarse en la póliza concreta |
| Acuerdo | Documento o decisión con alcance propio; no interpretar una firma aislada |
| Liquidación final | Conjunto de conceptos al terminar una relación; no confundir con una indemnización específica |
| Sucesión | Proceso relacionado con la transmisión de derechos tras un fallecimiento |
| Declaratoria | Resolución sucesoria cuyo alcance requiere lectura profesional |
| Mediación | Instancia regulada de gestión del conflicto; no es una sentencia ni aplica igual a todo caso |

## Términos de coberturas médicas

| Término | Qué debe entender el cerebro |
| --- | --- |
| Entidad | Organización que brinda o administra cobertura; distinguirla del plan |
| Plan | Conjunto concreto de condiciones y acceso; verificar nombre y versión |
| Cartilla | Red y reglas de acceso que se confirman por plan, zona y fecha |
| PMO | Piso de prestaciones obligatorias; no equivale a toda la cartilla de una marca |
| Copago o coseguro | Participación económica por uso según condiciones verificadas |
| Aportes | Recursos de un régimen cuya aplicación debe revisarse; no aseguran cuota cubierta por completo |
| Opción de cambio | Trámite personal sujeto a régimen, requisitos y confirmación |
| Alta administrativa | Inicio confirmado de una modalidad; no implica autorización de toda prestación |
| Preexistencia | Antecedente de salud con tratamiento normativo específico; no es un filtro automático de exclusión |
| Declaración jurada | Documento de información que debe completarse de forma verdadera por su canal apropiado |
| Reintegro | Mecanismo sujeto a condiciones y límites del plan |
| Continuidad | Necesidad de mantener atención y verificar fechas, red y autorizaciones |
| Autorización | Confirmación de una prestación concreta; no se deduce solo de una credencial |
| Prestador | Profesional o institución cuya participación debe verificarse |
| Régimen | Modalidad de acceso del titular que orienta qué reglas se deben consultar |

## Términos de automotores

| Término | Qué debe entender el cerebro |
| --- | --- |
| Versión | Configuración concreta dentro de un modelo; condiciona equipamiento y propuesta |
| Crédito prendario | Financiación con condiciones y garantía que se confirman con la entidad |
| Plan de ahorro | Sistema contractual diferente de un crédito; verificar administradora y condiciones |
| Valor móvil | Referencia del bien en un sistema de ahorro; no tomar un valor antiguo como actual |
| Cuota pura | Componente que debe distinguirse del pago total del plan |
| Adjudicación | Etapa del plan que no equivale por sí sola a retiro efectivo |
| Licitación | Mecanismo sujeto a reglas del grupo; no garantiza resultado por una oferta aislada |
| Integración | Fondos o requisitos que deben identificarse dentro de la propuesta concreta |
| TNA | Tasa nominal anual; no representa por sí sola todo el costo |
| TEA | Tasa efectiva anual bajo condiciones de capitalización |
| CFT | Indicador de costo financiero que se analiza con monto, plazo y cargos |
| Tasación | Evaluación del usado; una referencia inicial no equivale a valor firme |
| Dominio | Identificación registral cuya información se verifica mediante trámites pertinentes |
| Prenda | Afectación que requiere revisión para la operación; no declarar cancelación sin evidencia |
| Precio final | Alcance económico que debe detallar qué incluye la operación |

## Términos de Marketing y sistemas

| Término | Qué debe entender el cerebro |
| --- | --- |
| Lead o consulta | Interacción cuyo criterio se define antes de medirla |
| Oportunidad | Posibilidad comercial con un criterio acordado; no equivale a venta |
| Landing | Página orientada a un objetivo concreto |
| Conversión | Acción definida y verificada; puede ser distinta de una compra |
| CPL | Costo relacionado con consultas según un universo y período definidos |
| CAC | Costo de adquisición relacionado con clientes nuevos definidos |
| ROAS | Ingresos atribuidos a publicidad respecto del gasto publicitario |
| Margen | Dato necesario para evaluar resultados económicos; no se deduce del ingreso |
| UTM | Parámetros de referencia de campañas; no garantizan atribución completa |
| SEO | Prácticas para facilitar descubrimiento y comprensión; no compra posiciones |
| CRM | Sistema de relaciones y gestión; depende de estados y responsabilidades |
| API | Interfaz con acciones, formatos y permisos definidos |
| Webhook | Aviso de evento que puede requerir manejo de repetidos y reintentos |
| Idempotencia | Propiedad de un diseño que evita repetir un efecto al reprocesar una misma operación |
| Recuperación de conocimiento | Selección de información pertinente para una respuesta; no sustituye las reglas |

## Revisión y mantenimiento de fuentes

Las condiciones variables se verifican al preparar una respuesta concreta: stock, precios, promociones, cartillas, tasas, disponibilidad y canales. Las normas se revisan antes de una publicación o explicación que dependa de una fecha o procedimiento. El cerebro conserva quién confirmó cada dato y el ámbito al que se aplica.

Si una fuente cambia, no se borra la historia. Se agrega una revisión que identifica el dato anterior, la información nueva y el uso que queda suspendido hasta confirmar. La revisión de una fuente no autoriza a modificar automáticamente las reglas de los bots ni a contactar personas.
